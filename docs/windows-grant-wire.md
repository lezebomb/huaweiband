# VM Windows 签名授权线格式

这是隔离 VM 实验的二进制授权格式，由 C++ Provider 和 `BandKey.Core.WindowsGrantWire` 共同实现。现有 Android `/v1/approval` 使用 DER 签名和不同正文，不能直接转换为本格式的合法授权；未来设备必须明确签署这里的完整请求，并另行完成真实来源、距离、撤权及认证策略接入。正式代理没有启用本路线。

所有整数为小端，SID 为 UTF-16LE，签名为 P-256 / SHA-256、固定 64 字节 P1363 的 r||s。

| 偏移 | 字节 | 内容 |
|---|---:|---|
| 0 | 16 | ASCII `BANDKEY-WIN-V1`，后跟两个零字节 |
| 16 | 4 | Windows Session ID，非零 |
| 20 | 8 | 签发时间，FILETIME 1601 纪元毫秒 |
| 28 | 8 | 过期时间，恰为签发时间 + 30000 |
| 36 | 32 | CNG 随机 nonce |
| 68 | 368 | 本地账户 SID，含终止零，余下全部为零 |
| 436 | 64 | 对前 436 字节的签名，仅批准响应包含 |

请求 436 字节，批准响应 500 字节，附加或截断数据均拒绝。公钥为 72 字节 CNG ECDSA P-256 公钥 blob：8 字节头加 X/Y 各 32 字节。

Provider 只接受与自身内存中请求逐字节相同、配置 SID/会话匹配的响应；同时检查墙钟、单调时钟、仍锁屏、配置公钥仍有效，提交前再检查。验证不是消费；提交路径原子消费，失败也不自动重试。密码只在完成这些检查后才由 SYSTEM 读取加密保管文件，交给 LogonUI 的 Negotiate 认证包。序列化成功仍不是桌面解锁证据。

Exchange 目录仅用于公开请求/响应，SYSTEM/管理员可写，目标用户可读写；不在这里放置 Windows 密码。模拟私钥为当前 VM 用户 DPAPI 加密的测试材料。此用户可签名，故该测试来源不具有正式设备信任等级。Vault 则为独立的 SYSTEM/管理员专属目录，文件权限会在读取时再次核验。

原生测试包含签名篡改、上下文变更、超时、时间回退、并发消费、密钥轮换及无授权拒绝。互通测试由原生生成公开向量，.NET 验签并生成另一份签名，再由原生反向验签。全部合成向量只保存在被 Git 忽略的 artifacts 中。
