# BLE 长时间恢复补丁

本补丁只更新 Windows 用户态 BLE 助手，不重装手机、不改手环配对或 Windows 登录组件。它可以和原版手机 0.8.0、现有 VM 中继使用；0.9 原生请求恢复候选仍按其单独教程更新。

## 修复内容

旧监督器使用整个运行期间的 `Attempts < 4` 判断是否重试：即使恢复后正常传输很久，历史尝试次数仍会耗尽，第四次间歇故障就停止。现在区分总尝试与连续失败。

同一 GATT 连接至少完成 3 条双向流，且首次与最近一次完成的单调时间跨度达到 60 秒，才允许重置连续失败计数。只有连接成功、空闲时间、半条流或零散字节均不算恢复证据。完成指双方 EOF 收尾成功，不是 Windows 解锁或应用身份认证。

连续 4 次可恢复故障仍停止，重连间隔仍为 11／12／14 秒。协议错误和权限拒绝不重试；每次重连先释放旧订阅、通道和 Socket。运行截止时间、单条流 45 秒限制、TLS 指纹、一次性授权和不自动重发决定均不变。

故障历史保留最近 32 条，并另记累计数量及截断标志；JSON 新增 `failureCount`、`consecutiveFailures`、`recoveryBudgetResets`、`failuresTruncated`。界面继续区分当前传输与历史故障，不会因为后来恢复就抹去错误。

## 使用与回退

完整 Windows ZIP 为本机 `artifacts/BandKey-BLE-recovery-0.9.1.zip`。停止并关闭旧 BLE 助手，将 ZIP 完整解压到新目录，运行其中 Start-BLE.cmd，再填写原 VM 私网地址连接。不要把少数 EXE／DLL 混入旧目录；手机数据和公钥无需变化。

回退时停止新版，重新运行原目录的 BLE 助手即可。VM 内不用为这项补丁复制文件或运行安装器。新补丁未自动启动，等待手机连接后再进行实际验证。

## 已验证与限制

Windows Release 构建无警告／错误，集成检查 97/97 通过。新增 4 项检查覆盖：有足够成功流后可跨越原总尝试上限、短暂／空闲连接不能刷新额度、多轮恢复时日志有界、协议／权限故障仍停止；原有取消、截止时间、清理及真实回环 TLS 检查继续通过。

故障和健康流计数在这些恢复检查中是注入输入，未执行物理 GATT 断连，也未操作 VM 登录。这修复的是恢复策略缺口，不能证明 TCP 10053 或 BLE 流超时的根因已消除，长时间实机稳定性仍待验证。
