# 手环通知轮次与截止时间：0.5.2

0.5.1直接锁屏确认已获用户确认能解锁，但离开／返回测试中，用户在向外走时收到通知，点击未解锁，返回后未看到另一条。报告存在断连和3次通知尝试，不能证明哪一条何时实际在手环显示，也不能将已有的直接锁屏批准算成返回成功。

0.5.2仅修改手机通知：

- 每次后台实验使用独立显示编号，每条请求显示该运行内递增轮次，例如“VM确认 #AB12-3”。显示编号不参与认证，也不是密钥或原生nonce。
- 正文显示原生签名挑战的实际本地截止时刻，格式HH:mm:ss。没有从通知送达时重新延长30秒。
- 过期、已替换或重复点击会记录明确状态；只有原有PromptGate接受本轮点击时才进入既有签名路径。
- 报告只增添最后显示编号及截止时间，不导出nonce、设备标识或Windows凭据。

Android构建、签名与Lint通过，现有106项生产代码JDK检查通过。Windows、原生DLL、10秒刷新及30秒授权期限都未修改；不重复跑无关的原生或Windows构建。手机保留数据更新一次，原实验密钥与配对继续使用。
