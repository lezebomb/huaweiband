# 最少真机操作与判定标准

环境检查、APK 安装与服务范围诊断已执行，结果见 [实机记录](device-validation-20261017.md)。Mate60 手机按钮经 USB / BLE 到 VM 本地账户的结果另见 [分轮记录](mate60-validation-20261019.md)；真实手环按钮、距离与正式宿主机认证仍未通过。以下保留手环验证顺序；审核等待期安排见 [开发顺序](development-20261018.md)。

## 1. 核对设备

在一加 Ace 6T 的运动健康中确认 Band 11 Pro 已正常连接，记录手环名称、固件版本、如可见的蓝牙地址；记录运动健康/HMS版本。无需取消配对，也无需打开手环开发者模式。

把一加通过 USB 连接到电脑，打开 Android 开发者选项中的 USB 调试，在手机上授权这台电脑。用 `adb devices -l` 验证已授权设备；这些步骤不需要把手机作为每次解锁的人机确认点。

## 2. 华为服务申请

本应用 `dev.bandkey.bridge` 已取得正式 App ID，账号服务已开通，华为 APIs 使用协议已按用户明确确认签署。用户于 2026-10-17 确认 Wear Engine 申请正在审核。待平台审批通过后，按官方[配置说明](https://developer.huawei.com/consumer/en/doc/development/connectivity-Guides/addingappid-packagename-0000001050818013)再次核对 App ID、包名、签名指纹和 DEVICE_MANAGER / NOTIFY；审核中不等于已经获得权限。

本应用的公开 App ID 已写入 `android/gradle.properties`；其他开发者构建时可传 `-WearEngineAppId` 覆盖。最终 APK 的应用证书 SHA-256 见 `artifacts/android-signing.txt`；构建方式不变时应保持调试密钥不变。不要把 Windows 登录密码或 PIN写入任何服务配置。

## 3. 安装与能力查询

在明确选择的一加上安装 `artifacts/BandKey-bridge-debug.apk`。App 内授权蓝牙、通知和 Wear Engine 的 DEVICE_MANAGER / NOTIFY。选择正确设备 UUID；记录 Notify 能力值和固件版本。

- 如果授权被华为拒绝：先核对服务审批、App ID、包名、签名、运动健康版本；不要重新绑定手环来“修复”。
- 如果列表没有手环或 Notify 非支持：记录返回值，桥接路线尚未验证，不进入登录部署。
- 如果一加不支持而 Mate 60 支持：Mate 60 仅用于对照，不能把依赖 Mate 60 的结果当作最终方案达成。

## 4. 双向配对与按钮

按 README 互相导入公钥并核对完整指纹；Windows只监听专用局域网地址。Android启动前台桥接，锁屏手机，保留运动健康连接。Windows先关闭自动锁屏，核对手环广播并观察 Near。

手动锁定 Windows，使系统真正进入锁屏会话。若距离为Near且有新的签名挑战，手环应显示解锁/拒绝按钮。分别测试：发送成功但不点击、第一按钮、拒绝按钮、超时后再点击；电脑只能在第一个有效按钮事件后报告授权验证，所有测试仍不应直接进入桌面。

## 5. 距离与稳定性

先在自动锁屏关闭状态观察：坐在工位5分钟、近距离转身、手机熄屏、手环熄屏、走远30秒、回来、关闭/打开电脑蓝牙、电脑睡眠/恢复、手机离线/重新联网。

通过标准：静坐不频繁远离；真正走远持续满足阈值；扫描故障显示Unknown并取消就绪；恢复后需要新的稳定Near；不会循环弹窗。广播在手机连接期间长期静默时，应保留Unknown，不能把静默硬解释为远离。

只有完成上述观察，才由用户启用自动锁屏进行真实走远测试。保留系统 PIN/密码，以手动方式返回。记录锁屏请求和 WTS事件，不能把API调用成功当锁屏成功。

## 6. 后台恢复

在 ColorOS 应用设置中允许 BandKey 和运动健康后台活动/自启动；按需要关闭电池优化。测试手机熄屏30分钟、普通进程被回收、蓝牙重连、手机重启。系统“强行停止”会阻止许多自动恢复机制，不能声称绕过它。

补测取消场景：发送请求后停止桥接、改选手环、重新导入电脑，以及等待请求过期。停止/换配置后旧按钮不得提交授权，旧查询不得产生新通知；已发送的通知可能仍显示。重复点击、先拒绝后确认也只能处理第一次有效选择。代码模拟已通过，仍需真实 SDK 回调验证。

Windows可选注册 README 中的当前用户登录后任务，再测试进程异常退出与手动登录后的恢复。冷启动首次登录尚不提供手环解锁；不能将登录后自启宣传成开机登录服务。
