# 快速接近小补丁：0.8.0

0.7仍约10秒通知、2秒解锁。0.8处理一段确定存在的重复等待：已在电脑旁稳定连接时，锁屏不再清掉仍新鲜的物理接近证据；旧授权仍全部取消并生成新请求。只有原来已解锁、确实Near且证据新鲜才保留；未知、过期、解锁或真正走远仍重置。

固定手机模式新增“接近稳定等待”1～10秒，默认1秒；RSSI模式默认不变，持续断连锁屏仍15秒。手机只在连接状态变化时立即签名上报，并短时加快重连核对，正常心跳仍3秒。手环点击、10秒刷新、30秒授权、一次性验签完全保留。

## 仅5个文件，不重装

适用于VM中已有完整0.7 VmBridge运行目录。不要把这5个文件单独放空文件夹运行，运行时仍来自原目录。

1. VM中停止中继，关闭旧窗口。将原目录内下列5个同名文件先复制到一个备份文件夹。
2. VMware光驱切换到本轮 BandKey-Relay-Patch-*.iso，打开光盘 Patch，复制全部5个文件到原来的完整 VmBridge 文件夹，选择替换。
3. 从原目录运行 Start-VM-Bridge.cmd。新程序会只读加载当前VM账户已登记的手机公钥；只有一个私网IPv4时自动填监听地址。
4. 勾选固定手机，接近稳定等待先设1秒；自动锁屏按当前测试需要选择。确认手机地址仍为 https://127.0.0.1:19443，启动文字应有“0.8 快速接近”。
5. 手机由开发端保留数据更新一次并接好BLE。先保持VM桌面，不用重新导入公钥或改登录组件。

5个文件是 BandKey.exe、BandKey.dll、BandKey.Core.dll、BandKey.deps.json、BandKey.runtimeconfig.json，必须一起替换。补丁不含Credential Provider、安装器、密码、私钥或新配对资料。

## 检查与边界

核心151项、Windows88项、Android110项及构建／签名／Lint通过。新增5项针对性检查确认：只保留新鲜Near；普通接口仍默认重置；解锁／未知会话不能继承Near；锁屏仍需新签名请求；新的报告不能把旧的过期证据变成可继承证据。宿主机只读公钥读取仍被VM保护拒绝。

用户已将补丁5个文件替换进原完整中继目录，设接近稳定等待1秒；一加保留数据更新0.8.0一次，原生登录组件和公钥不变。本轮原地手动锁定VM，收到新通知后立即在真实手环确认，用户反馈“通知3秒钟，解锁1秒钟”，无需手动输入密码。这是单轮用户计时，相较0.7约10秒／2秒明显改善；没有独立WTS或同步时钟测量，不将粗略秒数当作精密延迟。
